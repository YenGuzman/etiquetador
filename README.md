# Etiquetador de Lesiones Papilares — Versión Web

Etiquetador de imagenes web con vinculacion a google drive por medio de la API de google.
Creado originalmente para tesis de grado sobre IA de asistencia con el diagnostico de cancer de mama en lesiones papilares.

## Arquitectura

- Backend: Python + FastAPI + SQLite.
- Frontend: HTML + JavaScript con Canvas
